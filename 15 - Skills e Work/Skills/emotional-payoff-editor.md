# Skill — emotional-payoff-editor

## Papel
Garantir que eventos grandes tenham preparação e consequência emocional.

## Rastrear
Vínculo construído → promessa emocional → ameaça → escolha → perda/ganho → reação imediata → cicatriz comportamental → callback posterior.

## Regra
Tragédia não vale pelo choque. Uma morte deve alterar decisões, relações e linguagem futura. Evitar luto descartável.

## Dependência universal
Obedecer [[story-bible-core]].
