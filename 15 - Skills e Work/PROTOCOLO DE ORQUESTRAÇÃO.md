# Protocolo de Orquestração

## Toda tarefa narrativa
1. Executar mentalmente [[story-bible-core]].
2. Classificar a tarefa.
3. Consultar somente especialistas relevantes.
4. Produzir proposta sem alterar status canônico.
5. Rodar [[continuity-editor]] antes de consolidar.
6. Se houver texto literário, rodar [[prose-editor]] e [[pacing-editor]].
7. Se o usuário aprovar como cânone, atualizar notas afetadas e changelog.

## Rotas
- Novo personagem → character + worldbuilding + conflict + continuity.
- Nova divindade/mito → mythology + power + worldbuilding + continuity.
- Nova criatura → mythology quando aplicável + creature + worldbuilding + power.
- Novo poder → power + mystery/foreshadowing quando relevante + continuity.
- Novo mistério → mystery + foreshadowing + showrunner + continuity.
- Capítulo → showrunner + chapter + scene + character + dialogue + pacing + continuity + prose.
- Morte importante → character + emotional payoff + mystery + showrunner + continuity.
- Mudança histórica → worldbuilding + mythology quando aplicável + showrunner + continuity.

## Bloqueio
Se a proposta contradizer CANON, parar a consolidação e apresentar conflito + alternativas. Não corrigir silenciosamente.
